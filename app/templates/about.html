About MedTrack Architecture

MedTrack is a decentralized-ready cloud healthcare operating system orchestrating patient queues, clinical electronic health records, and real-time biometric telemetry using AWS and microsecond-level synchronization.

Flask Core Engine

Modular Application Factory with Blueprint routing, strict session isolation, and cryptographic password hashing.

v3.0.0 Architecture
Amazon DynamoDB

High-throughput NoSQL tables for Users, Doctors, Patients, Appointments, Diagnoses, and Notifications with GSI indexing.

Single-Digit ms Latency
Amazon SNS Mesh

Instant publish/subscribe clinical event dispatching notifications for booking, confirmations, and diagnoses via SMS and email.

Real-Time Pub/Sub
EC2 & IAM Security

Hosted on elastic Amazon EC2 instances hardened with strict IAM least-privilege policies, TLS 1.3 encryption, and role RBAC.

HIPAA-Grade Security

Adaptive Dual-Mode Storage Mesh

MedTrack incorporates an intelligent persistence layer that adapts dynamically based on execution context. It allows development and demonstration with zero cloud setup while preserving 100% API compatibility with Amazon AWS.

1. Local In-Memory Mode
Currently Active
  • Zero cloud prerequisites or payment accounts required.
  • High-speed in-memory state with synchronous JSON persistence.
  • Complete simulation of Boto3 DynamoDB Key/Attr condition queries.
  • Local mock SNS dispatcher logging dispatches to file for auditing.
2. AWS Cloud Production Mode
Troven Labs Ready
  • Activated automatically whenever AWS credentials are provided in .env.
  • Seamlessly swaps to native Boto3 resource & client connections.
  • Direct queries against Amazon DynamoDB tables (us-east-1).
  • Real SMS/email dispatches through Amazon SNS topics.
