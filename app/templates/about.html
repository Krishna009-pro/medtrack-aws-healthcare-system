About MedTrack

MedTrack is a modern cloud healthcare system designed to deliver fast, secure, and reliable clinical workflow management.

Flask Application

Modular application factory with Blueprints, session handling, and role security.

Amazon DynamoDB

High-throughput NoSQL storage for users, appointments, doctors, and health records.

Amazon SNS

Automated event-driven notifications dispatched to clinicians and patients.

Dual Storage Mode

Seamless transition between offline Local JSON storage and live AWS Cloud mode.
