Project Overview

About MedTrack

MedTrack is a modern, cloud-based healthcare management system designed to streamline communication and coordination between doctors and patients by providing a centralized platform for booking appointments, managing medical histories, and submitting diagnosis reports.

Contact Support
Flask Backend

Built using modular Flask application factory with Blueprint routing, secure sessions, and input validation.

AWS DynamoDB

High-throughput NoSQL database storing users, doctors, patients, appointments, diagnoses, and notifications.

AWS SNS

Publish/subscribe messaging service delivering appointment updates and clinical notifications via email/SMS.

AWS EC2 & IAM

Hosted on scalable Amazon EC2 instances with strict IAM least-privilege security roles and policies.

Dual-Mode Architecture (SmartBridge Ready)

MedTrack features an intelligent adaptive storage engine designed specifically for local evaluation and cloud deployment:

1. Local In-Memory Development Mode
  • Zero external dependencies required (no AWS account or credit card needed).
  • Stores and retrieves data in fast Python dictionaries/lists with persistent JSON backup.
  • Outputs real-time terminal proof logs for evaluation and testing.
2. AWS Cloud Production Mode
  • Activated automatically when AWS credentials (e.g., from Troven Labs) are provided in .env.
  • Directly queries Amazon DynamoDB tables with boto3 resource conditions.
  • Dispatches real-time SMS and email notifications through Amazon SNS topics.
